# Norris Writer

Norris Writer is a standalone fiction writing app built on the [Visual Studio Code](https://github.com/microsoft/vscode) open-source codebase (MIT license). It keeps AI chat, Git, and a writer-focused workbench while stripping IDE-oriented developer surfaces.

## Development

```bash
npm install
npm run compile
./scripts/code.sh
```
